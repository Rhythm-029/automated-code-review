# Data Directory

This directory stores raw and processed data artifacts following TDSP repository organization guidelines.

## Subdirectory Structure
- [`raw/`](raw/): Storage location for unmodified raw Microsoft CodeReviewer dataset files.
- [`processed/`](processed/): Storage location for cleaned, filtered, and tokenized dataset splits ready for model fine-tuning.

*Note: Large dataset files are excluded from Git tracking via `.gitignore`.*
