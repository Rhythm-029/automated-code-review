# Model Evaluation and Inspection Reports

This directory stores quantitative benchmark metrics (BLEU, ROUGE-L, exact match) and qualitative inspection reports generated by the evaluation pipeline.

---

## Generated Artifacts

When executing `ml/evaluate.py`, artifacts are saved here:

```
reports/
├── README.md                  # This file
├── eval_results.json          # Aggregate metrics across test samples
└── inspection_report.md       # Qualitative side-by-side comparison
```

### Running Evaluation

To evaluate on the first 100 test examples:

```bash
python ml/evaluate.py \
  --dataset-dir dataset \
  --n-examples 100 \
  --output reports/eval_results.json
```
